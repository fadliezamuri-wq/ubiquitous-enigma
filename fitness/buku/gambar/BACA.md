# Gambar buku resepi

Letak gambar (`.jpg`, `.png` atau `.webp`) dalam folder ini, kemudian jalankan `npm run buku`.

- `kulit.jpg` digunakan untuk kulit depan (nisbah potret, contoh 1240×1240 atau lebih besar).
- Gambar lain digunakan bergilir untuk halaman resepi dan halaman bab, ikut susunan nama fail
  (`01.jpg`, `02.jpg`, ...). Lebih banyak gambar, lebih kurang ulangan. 100 gambar = satu gambar setiap resepi.
- Ruang gambar resepi berukuran 87×118 mm (potret 3:4). Gambar akan dipotong supaya penuh.
